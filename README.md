# Welcome to the Hall of Fame
Go ahead and try to join the ranks of the elite

## How to join the ranks of the elite
1. Firstly, you will need for fork your own version of this repo (located in the top right by the green "code" button")
2. Then, using whatever methods you wish, add a new line to `hallOfFame.json`
3. After committing to your forked repo, create a new pull request by clicking "contribute"
4. If you correctly added your name and GitHub username (it has to match who is authoring the pr) you will then be added to the hall of fame
