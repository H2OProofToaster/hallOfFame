# Welcome to the Hall of Fame
Go ahead and try to join the ranks of the elite

## How to join the ranks of the elite
1. Firstly, you will need for fork your own version of this repo (located in the top right by the star button)
2. Then, using whatever methods you wish, add a new line to `hallOfFame.json` using the same format as the previous ones (make sure that the "github" field matches your username, case insensitive)
3. After committing to your forked repo, create a new pull request by clicking "contribute"
4. If you correctly added your name and GitHub username you will then be added to the hall of fame
